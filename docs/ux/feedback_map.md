# Feedback map

Every player action and game event, what it looks and sounds like. Durations are at animation speed 1.0 and always go through `Settings.time()`; the reduced-motion column says what replaces movement, shake and flashes.

## Match

Named durations live in `config/ux.json` → `motion.durations` and are read through `Motion.time(name)` (`scripts/ui/fx/motion.gd`). Particles, rings and flashes are short-lived `FxBurst` nodes drawn in code (`scripts/ui/fx/fx_burst.gd`); with reduced motion `FxBurst.spawn` draws nothing. Input is never blocked by a non-awaited effect (deal-in, banner, float text, pip steps); the screen stays `is_busy()` only while the event sequence and the opponent run.

**Deliberately silent** (both channels were considered; silence is the choice):
- Opponent draw, energy refill and reshuffle: the player's own versions sound; doubling them on the opponent's turn would crowd the turn handoff (`turn_opponent` already marks it).
- Ambient loops (map halo, title light sweep and piece wave): constant motion with a sound would become noise.
- Hovering a map node you can't travel to, and locked set tiles: no tick, so the tick itself means "you can go there".
- The match-over score count-up: the victory / defeat stinger covers it (the run-end count-up does tick, once per figure).
- Settings saving: invisible and silent by design ("Saved automatically").
